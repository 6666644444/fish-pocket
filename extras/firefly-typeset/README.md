# Firefly 排版

让回答在手机上好读，接近 ChatGPT 讲题的样子：

- **公式**：值得单独看的公式放在自己的行上、居中显示；推导一步一行；最终答案加框（`\boxed{}`）；表达式里的某一部分可以在下面加括号注释（`\underbrace{}`）。
- **解题步骤**：分成几小步，每步一个小标题（如「第一步：配方」），公式单独成行，最后给出加框的答案。
- **彩色提示框**：只给少数几处要特别提醒的内容，不是每段都加。

  | 写法 | 颜色 | 用在 |
  |---|---|---|
  | `> [!NOTE]` | 蓝 | 定义、背景、补充 |
  | `> [!TIP]` | 绿 | 方法、技巧、捷径 |
  | `> [!IMPORTANT]` | 紫 | 重点、结论 |
  | `> [!WARNING]` | 橙 | 易错点、陷阱 |
  | `> [!CAUTION]` | 红 | 严重错误、禁忌 |

  标记后面可以写标题，例如 `> [!TIP] 技巧`。也可以直接写中文：`> [!重点]`、`> [!易错]`、`> [!技巧]`。在标记后面紧跟 `-`（如 `> [!NOTE]- 证明`），这一块默认收起，点标题展开。
- **画图**：讲函数图像、几何图形或数据时，有画图工具（`show_view`）的 Bot 会把图画出来；没有的就用文字说清顶点、交点、单调区间这些关键点。

写代码、写文件、一句话就能答完的问题，或者你另外要求了格式时，这些都不用。

## 在哪里显示得出来

- **Firefly App（新版）**：提示框是彩色的卡片，可以折叠。
- **网页版和其他 Markdown 工具**：GitHub 支持这种写法；不支持的地方会显示成普通引用块，开头带着 `[!TIP]`。如果你常在不支持的地方看，可以在设置里把 `callouts` 关掉，提示框会改成「**重点**：……」这样的写法。

## 设置

在插件页的设置里改，三项都可以不填：

| 项 | 默认 | 作用 |
|---|---|---|
| `callouts` | 开 | 关掉后不用 `[!TIP]` 提示框，改成加粗标签的引用 |
| `rules` | 空 | 你自己的排版要求，加在最后，优先于上面的规则（最多 1000 字） |
| `enabled` | 开 | 不卸载就暂时停用 |

## 怎么做的

这个插件只往系统提示词里加一段固定的排版说明（大约 1.5 KB），每次请求都一样，模型服务的缓存会把它存下来，所以每轮几乎不多花 token。子代理（subagent）不加，它们写的东西是交给上一级的，不直接给你看。插件不调用模型，不联网，不读写任何文件。

## 安装

在 Firefly 的「插件 → 安装插件」里：

- 选「从本地文件夹安装」，选这个文件夹；或者
- 填它的 Git 地址。

装好后新开一个对话试试，例如问「求 f(x)=x²−4x+3 的最小值」。
